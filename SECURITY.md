# Security Policy

## Reporting a vulnerability

This repository is private. If you find a security issue:

1. **Do not** open a public issue
2. Contact organization owners (`@StanceHub/owners`) directly via private channel / email on file

We will acknowledge the report and work on a fix before any wider disclosure.

## Baseline expectations

- No secrets in git
- Org requires 2FA
- Production LLM API keys stay in env / secret store, never in source
