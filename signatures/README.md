# CLA signatures

This directory stores Contributor License Agreement signatures collected by the
[CLA Assistant](https://github.com/contributor-assistant/github-action) workflow
(`.github/workflows/cla.yml`).

- Document: [`docs/CLA.md`](../docs/CLA.md)
- Signature store: `version1/cla.json`

Do not edit signature entries by hand unless fixing a bot/storage issue.
