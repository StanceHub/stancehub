# Private org vs public launch (plain English)

## Keeping the organization “private for a while”

GitHub organizations always have a public profile URL (`github.com/StanceHub`), but:

- If **all repositories are private**, outsiders cannot see your code or docs.
- That is what we mean by “keeping it private for now.”
- You do **not** need a custom domain or company email for this.

We stay private until founders decide IP ownership / company paperwork. That is smart, not a blocker for MVP coding.

## What we are NOT doing yet

| Item | Status |
|---|---|
| Public Community Edition (AGPL) | Later |
| Custom domain / email | Not required for MVP |
| Org avatar | Optional cosmetics |
| Many teams / many invites | Only owners for now |

## CLA vs public launch

- **CLA** = paperwork between contributors and the project (rights to use contributed code).
- **Public CE launch** = making the Community Edition repo visible to the world.

You can (and should) have a CLA while still private. Public launch comes later.
